# Arena Grounds Hub — тест Versus FFA

В меню Versus → Free For All доступна `Arena Grounds Hub` для 2–8 игроков. Клиент при подключении получает карту от сервера и отдельно её не выбирает. Режим Hide & Seek на этой карте не включён.

Исходный `Arena_Grounds_hub.unr` сохраняется без изменений (SHA-256 `25A8168CE20520179A24542DC75F0C649B07443BC8450420E176938992659D49`). В файле семь стартов 0–6. При запуске сервера с восемью местами `HPVersusGame` добавляет восьмой старт на проверенный пол рядом со стартом 0. Файл карты на диске при этом не меняется.

## Получателю полного тестового ZIP

Нужна собственная установленная Harry Potter and the Chamber of Secrets с M212 на Windows. Распакуйте тестовый ZIP целиком, откройте PowerShell в его корне и выполните:

```powershell
.\scripts\Setup-ArenaGroundsTestKit.ps1 -GameRoot 'C:\путь\к\установленной\игре'
.\Play-Menu-Test.cmd
```

В меню выберите Versus → Free For All → Arena Grounds Hub → Создать сервер. На втором ПК выберите Versus → Подключиться и укажите IPv4-адрес хоста и тот же порт. Пакет уже содержит donor v16, карту, тестовый `startup.unr`, собранные `HGame.u`/`M212Share.u` и журнал UCC. Для установки готовой сборки Python и Git не нужны.

Если подготовленная копия содержит штатный `startup.unr` с известным хешем, установщик сохраняет его как `Maps\startup.original-before-arena-kit.unr` перед заменой тестовой картой. Исходная установленная игра не меняется.

Шесть заклинаний выбираются Numpad 1–6. Выстрелы сейчас без кулдауна; статус READY в HUD не должен превращаться в длинное ожидание после первого каста. MUTE от Mimblewimble и DISARM остаются отдельными эффектами режима. Сетевая видимость, прыжок, Alt Free Look, анимации и лечение/ускорение требуют обычной визуальной проверки обоими игроками.

В `KIT_MANIFEST.json` записаны SHA-256 обоих игровых пакетов. Перед сетевым тестом сравните на двух ПК `hgameSha256`, `m212ShareSha256` и `arenaMapSha256` из `.local\runs\<session>\launch.json`. Разные сборки `M212Share.u` могут иметь разные GUID даже при одинаковом Git-коммите; оба ПК должны устанавливать один и тот же полный ZIP. Launcher предупреждает, если локальные пакеты расходятся с манифестом ZIP.

Если ошибка повторится, после закрытия игры на каждом ПК выполните команду для своей серверной или клиентской сессии:

```powershell
.\scripts\Launch-Multiplayer.ps1 -CollectSession 'имя-сессии-из-launch.json'
```

Передайте целиком каталоги `.local\runs\<session>` с обоих ПК. В них остаются `launch.json` и stdout/stderr; найденный engine log копируется в `engine-0.log`. Если `engineLogLocationVerified=false`, engine log в проверенных местах отсутствовал: это отдельный результат диагностики, а не успешный сбор клиентского журнала.

## Если уже есть подготовленный WorkRoot

Карту можно установить отдельно из оригинального `Maps.zip` или файла `Arena_Grounds_hub.unr`:

```powershell
.\scripts\Prepare-ArenaGroundsHub.ps1 -SourcePath 'C:\путь\к\Maps.zip' -WorkRoot .local\versus-v16-game
.\Build.ps1 -VersusV16
```

Скрипт проверяет SHA-256 перед установкой и не перезаписывает отличающуюся карту. Для пересборки исходников требуется настоящий Python 3; полный тестовый ZIP устанавливает готовые бинарники без пересборки.
