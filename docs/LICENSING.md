# Publication boundary

Upstream: https://github.com/metallicafan212/HP2UScriptDecompile

The upstream repository page examined on 2026-09-20 identifies the project as
a working decompile and says the Scaling-Patch branch requires Metallicafan212's
engine. No license is displayed in its root file list or repository sidebar.
This is not a grant to relicense the decompiled EA game.

Keep full sources, assets, executables, compiled packages, supplied archives and
runtime logs local. Track checksums, original mod classes, narrowly scoped source
patches and instructions instead. No license is asserted for third-party material.
Review the complete tracked tree and history before any public push.
