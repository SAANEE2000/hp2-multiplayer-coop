# Аудит v18 как donor для текущего Versus v16

Дата: 2026-09-24. Donor: `v18/v18/HGame/Classes`. Целевая база: текущая
воспроизводимая сборка `-VersusV16` с FFA на 2–8 игроков, Native movement,
выбором Harry/Ron/Hermione, раундами, death/respawn и `HPVersusHUD`.

## Что найдено

| Механика v18 | Реальное состояние donor-кода | Решение для текущего FFA |
|---|---|---|
| Rictusempra | Рабочий server-authoritative снаряд; урон 5–15 от заряда. Это копия уже используемой основы `HPVersusSpell`. | Оставить текущую реализацию и баланс 5–15. Не заменять её копией из v18. |
| Mimblewimble | Снаряд и server-side hit готовы. Эффект mute смешан со случайным 50/50 уроном, двумя таймерами и повреждёнными сообщениями; сброс при death/respawn отсутствует. | Взять визуал и server-side hit. Сделать детерминированный урон 3–8 и короткий server-authoritative запрет каста 0.75–1.50 с; сбрасывать вместе с остальными временными эффектами. |
| Expelliarmus | Есть полноценный атакующий снаряд с обработчиком 8–20 урона, но `ServerRequestCast` v18 его обходил и вместо выстрела создавал экспериментальный щит. Код щита дублирует выключение, держит бессрочный FX и не включён последовательно в death/respawn. | Включить проверенный путь снаряда 8–20. Экспериментальный shield-only перехват не переносить. |
| Flipendo | Server-side hit, урон 2–8 и импульс готовы. В donor он зависит от экспериментального щита. | Перенести урон и push без зависимости от щита; оставить сервер единственным источником damage/velocity. |
| Alohomora | Не наносит урон Harry, возвращает `False`; снаряд медленный и использует homing `SeekSpeed=5`. Полезен только для одиночных замков/объектов. | Не включать в боевой FFA whitelist. В Startup нет подтверждённых сетевых целей Alohomora. |
| Spongify | Не воздействует на игрока; пытается напрямую `Trigger`-ить `SpongifyPad` и актёров по имени класса. | Не включать в боевой FFA whitelist. Для него нужен отдельный аудит сетевой карты и pad-state. |
| `HPVersusHealthPickup` | Проверка authority и clamp до 100 правильные. После `SetTimer` actor вызывает `Destroy()`, поэтому respawn-таймер никогда не срабатывает. `bPicked`/`bAvailable` дублируются. | Переписать узко: +25 HP, max 100, server-only pickup, скрытие и повторное появление через 30 с без уничтожения actor. |
| `HPVersusSpeedPickup` | Authority-check присутствует, множитель 1.5 на 10 с. Срок не реплицируется для HUD; сброс есть только по Tick и не встроен в смерть, respawn и новый матч. | Перенести как server-authoritative buff 1.5×/10 с с явным client sync и обязательным reset на expiry, death, respawn и новый матч. |
| Wand / selection | v18 содержит whitelist слотов 0–5 и разные charge FX. Общий spawn остаётся серверным. | Расширить текущий whitelist только до четырёх боевых слотов: Rictusempra, Mimblewimble, Expelliarmus, Flipendo. Брать FX из выбранного класса. |
| Damage / cooldown | Урон проходит через server `TakeDamage`, что пригодно. Cooldown один общий 0.3 с; Expelliarmus обходит обычный spawn. | Сохранить единый server gate, добавить server-side cooldown по выбранному слоту: 0.35 / 0.70 / 1.00 / 0.60 с. Max HP остаётся 100. |
| HUD | В v18 отдельного `HPVersusHUD` нет. Health и временные эффекты показываются сообщениями; часть состояния не реплицируется. | Расширить текущий HUD: `HP current/100`, выбранное заклинание, готовность/cooldown, speed buff и mute. |
| Hagrid / HideSeek | Встроены прямо в PRI/Harry/cast/damage и пересекаются с Versus. Это незавершённая отдельная ветка. | Полностью исключить. Список персонажей остаётся Harry/Ron/Hermione. |

## Переносимый объём

Реализация ниже использует v18 только как справочник ресурсов и механик. В
текущую ветку добавляются три компактных подкласса проверенного
`HPVersusSpell`, два исправленных pickup-класса и узкие изменения в
`HPVersusHarry`, `HPVersusWand`, `HPVersusGame` и `HPVersusHUD`. Вся выдача
урона, применение временных эффектов, подбор и сброс остаются на сервере.
Максимальное здоровье не меняется и равно 100.
