## Почему два ПК должны получить один комплект пакетов

Сравнены `.local/builds/20260920-153659-290/M212Share.u.before` и `.local/game/System/M212Share.u`: оба 133,433 bytes, но SHA-256 соответственно `a9d240ba70e276ae0bcca0e5b93e6351c044f8a7911261bce091d08fdfbe992e` и `d1fe9f4b5c881824afb7e483d72badbdff8cea30394e4f9a128c4bb90c595dd1`. Все байты вне 16-байтового GUID по смещению 36 совпадают; внутри GUID отличаются 15 байтов. Следовательно, отдельная повторная сборка уже не обеспечивает равенство пакетов даже при совпадающем остальном содержимом. Для двух ПК нужен один приватно перенесённый комплект `HGame.u` + `M212Share.u`, сверенный по SHA-256 поверх собственных лицензированных development copies. Игровые пакеты не добавляются в публичный Git.
