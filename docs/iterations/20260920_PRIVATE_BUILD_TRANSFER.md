# Приватный перенос тестовой сборки — 20 сентября 2026

Добавлены `scripts/Export-TestBuild.ps1` и `scripts/Import-TestBuild.ps1`. Два ПК могут использовать один комплект `HGame.u` + `M212Share.u`, сохраняя GUID и SHA256. Повторный UCC make создаёт иной GUID даже при совпадающих остальных байтах; свидетельство приведено в [отчёте compile-cleanup](20260920_COMPILE_CLEANUP.md).

Экспорт создаёт ZIP только в локальном `.local/distribution`: два пакета, исходный лог UCC и manifest с точными размерами/SHA256. Он требует успешную запись сборки, совпадение WorkRoot, соответствие HGame записанному хешу и успешный лог. Если M212Share уже имеет записанный хеш, он также сверяется; для прежнего Build record без этого поля экспорт фиксирует хеш текущего M212Share. Архив проверяет целостность частного комплекта, но не является цифровой подписью независимого доверенного сборщика.

Импорт принимает только эти четыре точных имени, отклоняет дополнительные/повторные/traversal/symlink записи ZIP, проверяет все размеры, хеши, package headers и исходный лог до записи. `-ValidateOnly` ничего не меняет. Нужны помеченная development copy, обычные пути без reparse points и остановленные соответствующие Game/UCC. Старые пакеты и `last-build.json` сохраняются в `.local/imports/<id>`, затем пакеты заменяются по отдельности через атомарную замену файла; при обнаруженной ошибке выполняется rollback. Это не общая транзакция файловой системы при отключении питания; резервные копии остаются для восстановления.

В импортированной записи указаны `origin=imported-test-build`, `localUccRun=false`, `exitCode=null`, `sourceBuild`, `artifactIntegrityVerified=true`, SHA256 обоих пакетов и исходного ZIP. Поле `passed=true` относится к проверенному source PASS вместе с целостностью импорта, а не к несуществующей локальной компиляции. `exportCommit` — HEAD на момент экспорта; source commit неизвестен, если исходный build record его не сохранил.

Проверки `tests/test_testbuild_transfer.py` запускают настоящие скрипты в отдельном временном репозитории на синтетических данных. Минимальные заголовки пакетов не являются игровыми ресурсами и не проверяют UE loader. Проверены:

- Экспорт, проверка без записи, импорт, точное сохранение резервных копий и исходного дерева, повторный экспорт импортированного комплекта.
- Сохранение baseline flag и честного происхождения build record.
- Отказ до записи при повреждении второго пакета, дополнительных/повторных/traversal записях, отсутствии маркера, неправильном исходном PASS/хеше и ошибке UCC в логе даже с корректным хешем лога.
- Отказ при модели работающего соответствующего UCC и восстановление старых пакетов/build record после искусственной ошибки проверки первого заменённого файла.

Итог: **9 tests PASS на PowerShell 7 и Windows PowerShell 5.1**. Команда: `python -m unittest discover -s tests -p test_testbuild_transfer.py -v`; для выбора 5.1 перед запуском задаётся `HP2_TEST_POWERSHELL` путём к `powershell.exe`. Тестовый harness удаляет унаследованный PSModulePath, чтобы каждая оболочка загрузила собственные системные модули.

Во время этой работы активная `.local/game`, её пакеты и настоящий `.local/last-build.json` не изменялись; игра и UCC не запускались. Игровые архивы не публиковались. Перенос настоящей сборки и тест на двух физических ПК ещё не выполнены. Команды оператора добавлены в [локальный протокол](../LOCAL_TEST_PROTOCOL.md).
